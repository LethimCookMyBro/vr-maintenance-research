# Known Limitations

- This is a graybox research-development prototype, not a validated learning intervention.
- No Meta Quest 3 hardware run has occurred.
- Development source content is English placeholder content; Thai/Japanese equivalence is pending review.
- Video sources log playback intent methods but do not yet ship approved video media.
- Development researcher controls use IMGUI and are intentionally visible only in development mode.
- Low activity is currently interaction inactivity, not a clinical or cognitive measure.
- Current direct Play Mode runs prove schema, flow, and simulator integration; they do not prove user behavior, hardware tracking quality, or research outcomes.
- The eight invalid unreferenced v1 information assets remain locally visible until a permitted Unity Editor deletion action is available; only `_v2` assets are used by task definitions.
