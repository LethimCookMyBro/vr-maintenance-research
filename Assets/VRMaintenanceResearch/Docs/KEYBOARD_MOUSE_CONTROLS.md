# Keyboard and Mouse Controls

This prototype reuses the installed XRI Interaction Simulator. Use its in-editor overlay for the current binding display because simulator bindings may vary with the installed XRI sample version.

- Move the simulated headset/controllers with the simulator controls.
- Point/hover a task object or information board, then select to log the corresponding interaction.
- Grab the three neutral Training objects and place one in the Training socket.
- Use researcher controls only in `developmentMode`; they are not participant-facing study controls.
- The world-space Training instruction panel is informational and does not encode a task solution.

Run a short local simulator check after any XRI sample upgrade. Physical controller behavior must be validated separately on the intended headset.
